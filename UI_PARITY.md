# Omega Ruby UI parity tracker

The supplied Omega Ruby walkthrough is the visual source of truth. This work changes presentation only; every game-specific field, action, validation rule, capability and save operation remains in place.

- Shared Home header and current-save hierarchy.
- Saved-game cards, editor grid and save-management row.
- Fixed Home / Pokémon / Bank / Backups navigation in the main application shell.
- Full-page Switch Pokémon Boxes selector.
- Let’s Go Pikachu/Eevee Trainer Data editor: dark navy page, teal rounded status and input cards, cyan field labels, blue primary actions, matching typography and spacing.
- Pokémon Sword/Shield Trainer Data editor: the same shared Omega Ruby page, card, field, label, action and spacing treatment while retaining its native fields and save-copy workflow.
- Brilliant Diamond/Shining Pearl Trainer Data editor: the shared Omega Ruby page, card, field, label, action and spacing treatment while retaining its native fields and save-copy workflow.
- Pokémon Legends: Arceus Trainer Data editor: the shared Omega Ruby page, card, field, label, action and spacing treatment while retaining its native fields and save-copy workflow.
- Pokémon Scarlet/Violet Trainer Data editor: the shared Omega Ruby page, card, field, label, action and spacing treatment while retaining its native fields and save-copy workflow.
- Pokémon Legends: Z-A Trainer Data editor: the shared Omega Ruby page, card, field, nested Play Time row, label, action and spacing treatment while retaining its native fields and save-copy workflow.
- Let’s Go Pikachu/Eevee Party Move screen: shared Omega Ruby title hierarchy, cyan section label, teal status card, blue review action, typography and spacing.
- Pokémon Sword/Shield Party Move screen: the shared Omega Ruby workflow hierarchy, status card, review action, typography and spacing while retaining native PK8 movement behavior.
- Brilliant Diamond/Shining Pearl Party Move screen: the shared Omega Ruby workflow hierarchy, status card, review action, typography and spacing while retaining native PB8 movement behavior.
